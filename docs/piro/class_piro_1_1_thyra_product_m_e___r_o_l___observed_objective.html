Detailed Description

template<typename Real>
class Piro::ThyraProductME_ROL_ObservedObjective< Real >

Decorator of the reduced objective of a transient optimization problem.

It provides the observer calls and the objective recovery value that the steady-state optimization provides through Piro::ThyraProductME_Objective_SimOpt and Piro::ThyraProductME_Constraint_SimOpt:

  • observer->parametersChanged() is called when the parameters change;
  • observer->observeSolution() is called with the state at the final time, followed by observer->observeResponse(), for the initial guess and for the accepted iterates (every "Write Interval" iterations);
  • if "Objective Recovery Value" is set in the "Optimization Status" sublist and the forward solve did not converge ("State Solve Converged" = false in the "Optimization Status" sublist), value() returns the recovery value. The "Optimizer Iteration Number" in the "Optimization Status" sublist is updated at every update() call.

The final state is provided by the finalState function, which returns the state at the final time computed by the last forward solve if this was performed with the given parameters, and null otherwise. In the latter case the decorator recomputes the objective value at the given parameters.
