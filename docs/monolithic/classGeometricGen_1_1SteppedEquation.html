Detailed Description

template<typename T, typename weighttype>
class GeometricGen::SteppedEquation< T, weighttype >

Expression is a generic following method. a1 (x - x1)^b1 + a2 (y - y1)^b2 + a3 (z - z1)^b3 + c = expression_result if step values are given expression result is applied to a step function as following. expression_result < step1 value1 < step2 value2 < step3 value3 < step4 value4

Default values, c=1 a1=a2=a3=0 x'=y'=z'=0 b1=b2=b3=0 steps = NULL vals = NULL
