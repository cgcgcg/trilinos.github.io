Creates a strided mapping strategy. This class is useful for breaking up nodally ordered matrices (i.e. the unknowns in a FEM problem are ordered [u0,v0,p0,u1,v1,p1,...]). Current implimentation only supports a fixed number of variables

Parameters
[in]varsVector describing the blocking of variables
[in]baseMaporiginal Epetra_Map to be broken up
[in]commEpetra_Comm object related to the map
