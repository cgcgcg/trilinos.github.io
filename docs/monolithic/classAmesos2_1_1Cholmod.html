private

Currently, the following CHOLMOD parameters/options are recognized and acted upon:

  • "nmethods" : { int value }. Specifies the number of different ordering methods to try.
  • "print" : int value. Specifies the verbosity of the print statements.
  • "dbound" : int value. Specifies the smallest absolute value on the diagonal D for the LDL factorization.
  • "PreferUpper" : int value. Specifies whether the matrix will be stored in upper triangular form.
  • "useGPU" : int value. 1: Use GPU is 1, 0: Do not use GPU, -1: ENV CHOLMOD_USE_GPU set GPU usage..
  • "Enable_KokkosKernels_TriangularSolves" : bool value. Whether to use triangular solves.
  • "CholmodInt" : bool value. Whether to use cholmod int form.Whether GIDs contiguous the smallest absolute value on the diagonal D for the LDL factorization.
  • "SuperNodal" : bool value. Whether to use super nodal.
