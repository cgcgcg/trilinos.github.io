This function extracts those entities which are to be used to build a connectivity graph on the subdomain level. By default, we identify all entities with multiplicity 2. Afterwards, the corresponding entities can be obtained using the function getConnectivityEntities(). If short or straight edges should be omitted, the function flagEntities() has to be called in advance.
