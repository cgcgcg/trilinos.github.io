◆ setControlParameters()

void Amesos2::Control::setControlParameters ( const Teuchos::RCP< Teuchos::ParameterList > &  parameterList)

Sets various parameters concerning solver control.

Parameters
parameterListA Teuchos::ParameterList which contains the control parameters to set.


Supported Parameters:

  • "Transpose": { true | false }. If true , the solver instead solves .
  • "AddToDiag": std::string . The string should be a conforming representation of the scalar type of the matrix being used. The scalar will be added to non-zero diagonal entries of te matrix. The non-zero structure will not be affected.
  • "AddZeroToDiag": { true | false }. Zero will be added to the diagonal where diagonal elements are not present. Not supported for matrices which are "locked up" by the time Amesos2 sees them.
  • "MatrixProperty": { 0 | 1 | 2 }, where 0 is a general sparse matrix, 1 is a sparse diagonal matrix, and 2 denotes a symmetric sparse matrix. This parameter is only effective if the underlying solver supports the distinction.
  • "ScaleMethod": { 0 | 1 | 2 ... }, where 0 denotes no scaling, 1 is the underlying solver's first method, 2 is the solver's 2nd alternative, and so on.
