Detailed Description

template<class Matrix, class Vector>
class Amesos2::Lapack< Matrix, Vector >

Amesos2 interface to the LAPACK.

This Amesos2 interface uses a sequential, dense solver based on the LAPACK routines. This interface exists mostly for pedagogical purposes (to contrast sparse and dense solver performance), but could be useful in cases where the input matrix is sparse but "almost dense".
