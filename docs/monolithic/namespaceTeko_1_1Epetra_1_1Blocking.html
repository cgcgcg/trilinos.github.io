const MapPair Teko::Epetra::Blocking::buildSubMap ( const std::vector< int > &  gid,
const Epetra_Comm &  comm 
)

Build maps to make other conversions. This function builds a map using a vector of global ids local to this processor. It also builds a seperate map that (globally) starts from zero. For instance if the following GIDs are passed in PID = 0, GID = [0 2 4 6 8] and PID = 1, GID = [10 12 14] the the two maps created are Global Map = [(PID=0,GID=[0 2 4 6 8]), (PID=1,GID=[10 12 14])] Contiguous Map = [(PID=0,GID=[0 1 2 3 4]), (PID=1,GID=[5 6 7])]

Parameters
[in]gidLocal global IDs to use
[in]commCommunicator to use in construction of the maps
Returns
A pair of maps: (Global Map, Contiguous Map)

Extract the (i,j) sub block described by a vector of map pair objects from a CRS matrix. The first of map in the ith pair describes the rows to be extracted, while the second pair defines GID numbering of the new block. Similarly with the jth pair (except for columns). This "refills" an operator already created by buildSubBlock. This only replaces the sparsity pattern of the matrix.

Parameters
[in]iIndex of the map to use to define the row space
[in]jIndex of the map to use to define the columns space
[in]ASource CRS matrix
[in]subMapsVector of maps created by the buildSubMap routine.
[in,out]matDestination matrix with a fixed nonzero pattern. Most likely this operator would come from the buildSubBlock routine.
