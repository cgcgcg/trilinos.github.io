Inject Teko into a solver builder with a specified name. Note that the builder is used to define the default solvers in Teko. Therefore any dynamically specified solver/preconditioner, will be inherited by Teko. This relationship does not persist, so no solvers added to the builder after the call to addTekoToStratimikosBuilder will be inherited. Finally, to avoid circular references Teko will not include itself in that list of solvers/precondtioners.
