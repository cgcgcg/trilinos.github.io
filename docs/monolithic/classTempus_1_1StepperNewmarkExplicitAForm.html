Newmark Explicit time stepper.

This is the specific case of the more general Newmark time stepper where this stepper is explicit ( ) (i.e., no solver used).

Note that with useFSAL=false and are not at the same time level at the end of the time step (i.e., they are not sync'ed).

To have them at the same time level, we can use the First-Same-As-Last (FSAL) principle where the function evaulation from the last time step can be used as the first function evalulation of the current step.

The default is to use FSAL (useFSAL=true), but will also work with useFSAL=false. Using useFSAL=true does assume that the solution, , its time derivative, , and its second time derivative, , are consistent at the initial conditions (ICs), i.e., . For example, if the subclass implements a large data structure like a sparse matrix, VERB_NONE should print nothing at all, VERB_LOW should print data relative to the dimensions and number of entries of the matrix, and VERB_EXTREME may print all the entries of the matrix.
