Teuchos::ArrayRCP<GlobalOrdinal> Tpetra::Details::DistributedContiguousDirectory< LocalOrdinal, GlobalOrdinal, NodeType >::allMinGIDs_
private

Minimum global ID for each process in the communicator.

This array is only valid if the user's Map (map_) is distributed and contiguous. Otherwise, it remains empty. It is allocated in the constructor if necessary.

This array has map_->getComm ()->getSize ()+1 entries. Entry i contains the minimum global identifier (GID) of process i in map_'s communicator. Note that on processors with no Map entries, this array will store std::numeric_limits<GlobalOrdinal>::max(). Thus, this array is not necessarily monotonically non-decreasing. The last entry contains the maximum GID in the directory.

The directory uses this array to map from GID to process ID, when the GIDs are distributed contiguously in increasing order over the processes. This array allows the directory to compute the mapping locally, without communication, for any given GID, whether or not it is owned by the local process.

Note
To implementers: This is a potential memory bottleneck if the number of processes P is large and the allowed memory usage per process is small. This should only be a problem if , where N is the global number of elements. In this case, it would be more memory scalable to use reductions or scans to figure out who owns what.
