Construct a shallow wrapper to the user's C[R|S]S matrix.

The data passed in must persist at least as long as the CrsMatrix.

This interface is written in terms of a CrsMatrix; use make_transpose in this function and is_lo in the solve functions to solve the various combinations of upper/lower triangles stored in CRS/CCS format.

An implicit unit diagonal is permitted. If there are no diagonal elements, a unit diagonal is assumed. If only some diagonal elements are missing, preprocess will throw the exception NotFullDiagonalException.

If the matrix is not triangular, preprocess will throw NotTriangularException.

Parameters
n[in] Dimension of the matrix.
rowptr[in] Base-0 index pointers into col. Array has length nrow+1, where rowptr[nrow] is the number of nonzeros.
col[in] Ordered base-0 index pointers to columns.
val[in] Matrix values.
make_transpose[in] Make the transpose of this matrix. Set this to true, for example, to make a CRS matrix from a CCS one.
make_transpose[in] Take the complex conjugate of the entries of this matrix. Set make_transpose = true, make_conj = true to get the conjugate transpose of this matrix.
